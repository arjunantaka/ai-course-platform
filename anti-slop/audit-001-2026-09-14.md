# Anti-Slop Audit 001 · KrasCourse

Tanggal: 2026-09-14. Ruleset: antislop core (R-01..R-38) + antislop-ui + antislop-code
+ antislop-copywriting. Mode: AFTER (audit proyek existing, fix langsung disetujui owner).
Scope: seluruh `src/` (UI, komentar kode, copy) + `app.html`.

## Temuan & status

### Hard Gate

1. **R-25 kontras**: `text-zinc-400` (±2.5:1 di putih) dipakai untuk teks nyata:
   footer layout, breadcrumb lesson/kuis, "menit baca", meta kartu admin, judul lesson
   selesai + label menit (LessonTree, detail kursus), helper kuis, skor "/5".
   → **FIXED**: semua naik ke `zinc-500` (4.6:1 ✓); label tombol disabled ke `zinc-500`.
2. **R-03 tap target**: tombol primer `py-2.5` (±40px < 44px) di 10 lokasi.
   → **FIXED**: `py-3` di semua tombol primer + input pencarian setinggi tombol.
3. **R-15 CTA generik**: "Jelajahi kursus" (padanan "Explore").
   → **FIXED**: diganti "Lihat semua kursus".
4. **R-26/R-35 favicon**: `/favicon.ico` 404; aset svg tak dirujuk.
   → **FIXED**: favicon ter-wire di `app.html` (mark "K" teal dari identitas teks,
   bukan aset baru).
5. **R-02 em/en-dash** di komentar & teks internal (`utils.ts`, `courses.ts`,
   `generate.ts`, `mock.ts`, `quiz/+page.server.ts`).
   → **FIXED**: koma/titik/hyphen. Karakter yang tersisa hanya di string prompt AI
   (tidak pernah dirender) bila ada.

### Purpose-Gate

6. **R-11 radius seragam**: pill di semua elemen (tombol, input, opsi kuis, badge).
   → **FIXED**: sistem radius bervariasi, terdokumentasi di `DESIGN.md`
   (CTA pill; input `rounded-lg`; opsi kuis `rounded-xl`; kartu `rounded-2xl`; badge `rounded-md`).
7. **R-08 panah default**: `→` di hampir semua CTA.
   → **FIXED**: panah hanya tersisa di navigasi arah nyata (kuis "Soal berikutnya →",
   prev/next lesson). CTA masuk-halaman tanpa panah.
8. **Meta tag kosong**: `app.html` tanpa description/og.
   → **FIXED**: description + og:title/og:description (tanpa og:image, tidak mengarang aset).
9. **antislop-code komentar dekoratif**: banner `// --- ---`, `// ----- -----`,
   `/* ===== */` (hooks, courses.ts, generate.ts, app.css); catatan kuis 3 baris.
   → **FIXED**: satu baris polos, catatan panjang dipangkas ≤2 baris. Komentar bernilai
   (constraint drizzle, recovery restart, pipeline sanitize) dipertahankan.

### Quality Locks / polish

10. **R-37/R-31**: arah desain hanya ada di percakapan. → **FIXED**: `DESIGN.md`
    (dials, palet, radius, motif, voice) + alasan satu baris per keputusan.
11. **R-32 focus**: indikator fokus tidak konsisten. → **FIXED**: satu rule global
    `:focus-visible` ring teal di `app.css`.
12. **Skip link**: tidak ada. → **FIXED**: "Lewati ke konten" di layout.
13. **Tipografi**: heading rapuh orphan; angka proporsional. → **FIXED**:
    `text-wrap: balance` (h1-h3) + `tabular-nums` di angka skor/soal.
14. **Anchor jump** → **FIXED**: `scroll-behavior: smooth`.

## Temuan lanjutan (ditemukan saat click-through R-35)

    `STATUS_LABELS.published: 'Published'`, frasa "sebelum publish" (form create).
    → **FIXED**: "Terbitkan"/"Jadikan draft", label "Terbit", "sebelum diterbitkan".
16. **R-15 judul katalog**: "Jelajahi kursus" (h1 + title) juga generik.
    → **FIXED**: "Katalog kursus".
17. **Emoji state**: `✅` di daftar lesson admin, inkonsisten dengan `✓` UI lain.
    → **FIXED**: diganti `✓`.
18. **R-11 chip "Kuis"** di kurikulum masih pill. → **FIXED**: `rounded-md`.
19. **Regresi title**: app.html sempat punya `<title>` yang menimpa judul
    per-halaman (dua tag title). → **FIXED**: title dihapus dari app.html; tiap
    halaman (termasuk error + 4 halaman admin) men-set title sendiri, terverifikasi
    9 halaman.
20. **Favicon 404**: aset ada di `src/lib/assets` (tidak tersaji). → **FIXED**:
    dipindah ke `static/favicon.svg`, HTTP 200 `image/svg+xml`.

## Sengaja dipertahankan (dengan alasan)

- Light mode tanpa toggle: keputusan owner eksplisit (R-21 menghormati arah brand).
- Tanpa halaman legal/footer link tambahan: halaman belum ada; link mati melanggar
  R-24/R-38. Menunggu halaman sungguhan.
- Badge level pill kecil → jadi `rounded-md` (bagian sistem radius). Label "Modul N"
  uppercase tracking-wide di pohon lesson dipertahankan: penanda semantik
  pengelompokan, tracking ringan (bukan ekstrem), alasan tercatat di DESIGN.md.
- Komentar berisi `→` (alur proses, bukan tanda baca prosa) dipertahankan.
- Karakter `✓` di toggle lesson & pohon: indikator state nyata, bukan dekorasi.
